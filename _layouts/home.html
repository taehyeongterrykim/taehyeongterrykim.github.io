posLD

posLD is a natural language processing tool that computes lexical diversity using Moving-Average Type-Token Ratio (MATTR) across part-of-speech categories — specifically verbs and nouns — for corpus linguistics research. posLD allows researchers to examine how lexical diversity varies across word classes (Kim, Larsson, Kaatari, Wang, & Sundqvist, 2026).

Download for macOS

macOS (M1/M2/M3, macOS 10.15+)
Unzip → double-click posLD.app

Download for Windows

Windows (64-bit, Windows 10+)
Unzip → double-click posLD.exe
